# 基盤づくり：Gate 1 の承認のページの要点

**目的**：機能を作り、確認し、育てていける技術の土台を作る

**今あるものへの影響**

- ページを作って左の並びから開く：ほかのチケットの計画の行を変えるか消す。できることに「自分が、アプリの中で明るい画面と暗い画面を切り替える。最初は端末（Mac や Windows）の設定に合わせて開き、アプリの中で選んだら、その後は選んだほうで開く」を足す
- 自分の Mac と Windows で使い始める：ほかのチケットの計画の行を変えるか消す。できることに「自分が、版の印を付けてビルドされた新しい版のアプリを、Mac と Windows に自分で入れ直す」を足す、作らないものに「アプリが新しい版を見つけて自分で入れ替わること（自動のアップデート。一般に配るときに足す）」を足す
- アプリは Rust で作る（人の指定。速さを大事にするため）：画面の作り方を問いで決めたので、前提の事実に書き足す。前「アプリは Rust で作る」、後「アプリは Rust で作る。そのうち処理の中心とデータは Rust、画面は Web の技術（TypeScript）で描く」

AI は、これらへの影響と、前の仕様とのぶつかりを深く確認しています。

**このチケットで決めること**：問い 4 個、後で変えにくいもの 6 個

AI が提案した要件と具体例は、問いと一緒にページの「AI の提案と問い」で見られます。

全文と画面の画像は PR にもあります：https://github.com/aoyagiry/yakyu/pull/2
