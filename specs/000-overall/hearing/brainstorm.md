# 000-overall の壁打ち

## 人が話したこと

- Rust で高速なアプリを作りたい。野球は関係なくていい
- デスクトップアプリ。Notion みたいな感じの、メモ帳にもカレンダーでの予定管理にもチケット管理にも ToDo 管理にも使える万能アプリがいい
- データの作りは A（すべてをページとして持ち、見え方で切り替える）がいい
- 共有する仕組みもほしいが、最初は一人でいい
- OS は Mac でも使いたい（Windows と Mac）
- 同じデータを両方で見たい。Mac と Windows を持っている人が、わずらわしさを感じずに両方から同じページを見られるようにしたい
- 最初はまずメモから。ほかにも万能アプリとしていいものがあれば順次追加したい
- 同期は A（アカウントでログインして同期する）で。いずれは一般に配りたい
- ネットにつながっていないときも使え、つながったら自動で同期する形がいい。配布の形は未定
- 見た目や使い心地は、洗練されている感じがいい。AI 臭は消す。ユーザーの操作に対して気持ちいいフィードバックが必要
- 安っぽい広告まみれの無料アプリとは一線を画す、は絶対目標。意味は「見た目と品質で差をつける」で、広告を入れるかどうかは配り方と一緒に決める

## 言い直し（人が確認した）

- 目的：メモ、予定、チケット、ToDo を 1 つにまとめた万能のデスクトップアプリを作る。Mac と Windows の両方で、同じページを手間なく見て書ける。見た目と品質で、安っぽい広告だらけの無料アプリとはっきり差をつける（絶対の目標）。いずれは一般に配る
- 範囲：
  - データの作り：すべてを「ページ」として持つ。日付や状態などの項目を付けると、カレンダー、チケットのボード、ToDo の一覧という見え方で同じページを並べられる
  - 最初に作るもの：メモ。カレンダー、チケット、ToDo の見え方や、そのほかの便利な機能は、後から順に足す
  - 使う人：最初は自分一人。共有は後で足す
  - 動く環境：Windows と Mac。Rust で作り、速さを大事にする
  - 同期：アカウントでログインし、サーバーを通して同期する。ネットにつながっていなくても読み書きでき、つながったら自動で同期する
  - 一般に配る前提で最初から作るもの：ログイン、データを預かるサーバー、ほかの人のページが見えないこと、通信の暗号化
  - 後のチケットにするもの：ユーザー登録の画面、パスワードを忘れたときの手続き、料金の仕組み、共有
  - 見た目と使い心地：洗練されている。AI がよく作るありがちな画面にしない（紫から青へのグラデーション、どこにでもある絵文字のアイコン、同じ形のカードを並べただけの配置、中身の無い飾りの言葉など）。操作するとすぐ、気持ちよく反応する
- 具体例：
  - Mac でメモを書いて、後で Windows でアプリを開く → 同じアカウントでログインしていれば、そのメモが見える
  - ネットにつながっていない状態でメモを書く → 書けて、保存される。ネットにつながると自動で同期され、もう一方のパソコンでも見える
  - ページを開く、文字を打つ、ボタンを押す → 待たされたと感じさせずに画面が変わる。済んだことがさりげなく分かる
  - 別の人が自分のアカウントでログインする → 自分のページは見えない

## 相談したこと

- 機能を別々に作るか、同じデータを見え方で切り替えるか：人が選んだ（A：すべてをページとして持ち、見え方で切り替える）
- 同期のやり方：人が選んだ（A：アカウントでログインし、サーバーを通して同期する）
- ネットにつながっていないときの扱い：人が選んだ（読み書きでき、つながったら自動で同期する）
- 「広告まみれの無料アプリと一線を画す」の意味：人が選んだ（見た目と品質で差をつける）
- 配布の形（無料、買い切り、月額）：決めていない
- 広告を入れるかどうか：決めていない（配り方と一緒に決める）
- ネットにつながっていない間に 2 台で同じページを書き換えたときの合わせ方：決めていない
