# 動く試作
screen-mock（`SKILL.md`）の「4. 動く試作」。プロダクトリードが動く試作の回と伝えたときに読む。節の名前だけで指している所は、SKILL.md の節である。

静的な画面をもとに、押したときの動きを付けた `proto-<SCR の ID>.dc.html` を scratchpad に書き、`files` でキャンバスの `project/` に足して公開する。リポジトリの `project/` には入れない。`canvas.json` に試作の board を足すなら、リポジトリの `project/canvas.json` にも同じ変更を入れる（次の写しで、人の直しと取り違えないように）。承認と Gate 2 で比較する相手は静的な画面のまま。

押したときの動きは、ボタンの押下（`<button type="button" onClick="{{…}}">`）で付ける。フォームの送信（`<form onSubmit>`、`type="submit"`）は使わない（キャンバスは画面を枠の中で動かし、その枠はフォームの送信を許していないので、押しても何も起きない）。動きは自分では確認できないので、報告に「動きは確認していない」と書く。
