# デザインシステムの値を変える
screen-mock（`SKILL.md`）の「デザインシステムの値を変える」。デザインシステムの値か土台の CSS を足すか変えるときに読む。節の名前だけで指している所は、SKILL.md の節である。

1. design-system のスキルの「2. 直す」で、デザインシステムを直して公開し直し、`_tech/design.yaml` と `_tech/ds/<フォルダ>/` の正本（tokens.css、base.css）を合わせる
2. 今ある値か土台の CSS の宣言を変えたときは、デザインシステムを使う、ほかの領域のキャンバスにも、`ds/<フォルダ>/` の tokens.json、tokens.css、base.css を入れ直す（サーバーの中でコピーする。リポジトリの各領域の写しは mock-render が正本から写す）。モックは変数と土台の CSS で書いてあるので、描き直しは要らない。値が及ぶ画面の元を、このチケットの screen-changes.yaml の screens に `change: modified` で載せる（画面例は載せない）。その領域の 0 も行う
3. 値か宣言を足しただけなら、ほかの領域には何もしない
4. 報告に、足した値と、変えた値の前と後、土台の CSS で足すか変えた宣言、載せたほかの領域の画面を書く
